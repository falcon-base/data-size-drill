# データ量ドリル

情報Ⅰ「情報のデジタル表現」第7回（データ量の計算）の乱数問題ドリル．紙のワークシートと併用する．単一の `index.html`．外部ライブラリ・外部通信なし．

## 生徒向け
- 式は紙に書いて，答えだけ入力する（単位は書かない）．Enter キーで答え合わせ．
- 正解でも誤りでも，あとに模範の式が出る．1 回目の誤りはもう 1 回やれる．
- 4 段階：① 換算 → ② 立式 → ③ 考査型 → ④ 圧縮率．**1回目の答えで 3 問連続正解**すると次へ．段階は上のメニューからいつでも選べる．
- 数値は電卓なしで解ける形だけ．答えは整数か小数第1位まで．

## 教員向け
- 記録（正解数・連続正解・クリア）はその端末のブラウザの中だけ（localStorage）．アカウントも教員画面もない．端末を替えると最初から．「記録を消す」で初期化．
- 公開は GitHub Pages を想定．リポジトリ名 `data-size-drill`（公開前）．
- 自己検査：`index.html?selftest=1` を開くと，各段階 3000 問を生成して割り切れなどを検査し，ページ下とコンソールに結果を出す．
- 設計と問題の型の一覧は `SPEC.md`．

## 決定事項
- 連続正解の数え方：1回目の答えで正解した問題だけ．1回目の誤り・答えないまま離れる（メニュー選択・再読み込み）で 0 に戻る．
- ④の圧縮率は小数第1位まで厳密に表せる図だけ出す．紙の 78.125％（小数第3位）のような問題は出さない．
- 用語は「1フレームのビット数」．紙の版3の「1フレームのデータ量」とのそろえ方は，博士の確認待ち．

## 検査の結果
- 検査: qa-scizor（実装検査）．2周（1周目 要修正 Major 3・Minor 11 → 修正 cf19afe → 2周目 合格）．最終判定：合格（2026-10-10）．
- 乱数の全数検査: 独立した検算コード（問題文から答えを計算し直す）で各段階 20000 問×2 seed，計 160000 問を生成し，不一致 0．全問が整数か小数第1位まで．模範の式は文字列を読み直して答えと一致．④は符号化を独立に実装して，圧縮後ビット数・圧縮率を検算．自己検査（?selftest=1，12000問）も失敗 0．
- 画面と操作: 4段階の遷移（3問連続正解でクリア，1回目誤り→もう1回，2回目誤り→模範の式，1回目の誤り・未回答で離れると連続は0），Enter で答え合わせと次へ，全角・カンマ・％・単位付き入力の扱い，375px と 1366×768 で横スクロールなし・④を開いた直後に冒頭の一行と問題文が見える，localStorage が使えなくても動く，外部通信なし．
- 残る小さな点（合格を妨げない）: 全段階クリア時のボタン文言／SPEC.md 26行の一文／約分の説明の括弧．
- 未確認: 実機の Chromebook．
