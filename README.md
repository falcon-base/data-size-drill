# データ量ドリル

情報Ⅰ「情報のデジタル表現」第7回（データ量の計算）の乱数問題ドリル．紙のワークシートと併用する．単一の `index.html`．外部ライブラリ・外部通信なし．

## 生徒向け
- 式は紙に書いて，答えだけ入力する（単位は書かない）．Enter キーで答え合わせ．
- 正解でも誤りでも，あとに模範の式が出る．1 回目の誤りはもう 1 回やれる．
- 4 つの種類：文字・音・静止画・動画．好きな順に選べる．各種類で**1回目の答えで 3 問連続正解**すると ✓．4 つすべて ✓ で「全部クリア」．問題は，要素がそのまま並ぶ素直な問題（約 6 割）と，ひとひねりの問題（約 4 割）が混ざります．
- 数値は電卓なしで解ける形だけ．答えは整数か小数第1位まで．

## 教員向け
- 記録（正解数・連続正解・クリア）はその端末のブラウザの中だけ（localStorage）．アカウントも教員画面もない．端末を替えると最初から．「記録を消す」で初期化．
- 公開は GitHub Pages を想定．リポジトリ名 `data-size-drill`（公開前）．
- 自己検査：`index.html?selftest=1` を開くと，各種類 3000 問を生成して割り切れなどを検査し，ページ下とコンソールに結果を出す．
- 設計と問題の型の一覧は `SPEC.md`．

## 対戦モード（班の合言葉・リーグ戦）
- 画面上部の「対戦」から入る．班のみんなで同じ合言葉（数字4桁）と種類（ふつうはミックス）を入れて，同時に「開始」．「3・2・1」のあと 3 分間，同じ問題が同じ順で出る（合言葉・種類・問題番号から決まる）．
- 1回目の答えで正解 +1，誤答 −1，パス 0（「パス」ボタンで答えと式を見て次へ．誤答は答えと模範の式を約 2 秒見せて次へ．Enter で先送り）．時間切れで終了し，得点・正解数・誤答数を見せ合う．
- 結果は保存されず，個人練習の記録にも影響しない．通信なし．
- 終了画面は，結果を見せ合えるように，終了から1.5秒は「もう一度」「メニューへ」が効かない（Enter を何度押しても結果は消えない）．対戦のプレイ中は，画面を広く使うため上の見出し部をたたむ（設定・カウントダウン・終了画面では出る）．
- 注意：対戦に入る前に答えていない練習問題があり，対戦中に再読み込みすると，個人練習の離脱と同じ扱いで連続正解が 0 に戻る（対戦そのものは練習の記録を変えない）．練習の問題に答えてから対戦に入るのが安全．先生は `?roundsec=10` のようにラウンド時間を短くして試せる．
- 開始前に「合言葉 4821・種類 ミックス」の確認画面が出る．班のみんなと同じか確かめてから「合っている：開始」．
- 種類：ミックス（4 種類から出る）・文字・音・静止画・動画．既定はミックス．仕様と決定性の仕組みは `SPEC.md`．

## 教員用画面（班分け）
- 入口：`index.html?teacher`，または生徒の画面の一番下の小さな「教員用」リンク．
- 出席番号の人数（6〜60）と欠席の番号を入れて「グループを作る」と，3 人か 4 人の班にランダムに分かれる（班名 A班・B班…，番号は昇順）．ラウンド1〜3それぞれに，班ごとに違う合言葉と種類が出る．種類はラウンドごとに選び直せる（既定は3ラウンドともミックス）．
- 班の発表後はロックされます（欠席・人数・やり直し・新しく作るは押せません）．直すときは「班を解除して編集」を押し，確認で「はい」を選ぶと班が消えて，作り直せます．
- 合言葉は班ごとに先頭の桁が決まっている（A班＝1…I班＝9，J班＝0．11班以上は2桁）．班の拠点（最小の出席番号の席）も表示される．「やり直し」は班の発表の前だけ押す．欠席・遅刻は班を作り直さず，人数を数え直す（2人以下の班は他の班に入る）．
- 班と合言葉は教員の端末のブラウザに保存され，再読み込みしても変わらない．「新しく作る」で消える．扱うのは番号だけ．
- リーグ戦の順位点は紙で数える．
- 授業での使い方：①教員が班を作る → ②各班が自分の班の合言葉と種類（ラウンドごと）を端末に入れて同時に開始 → ③終了画面の得点を班で見せ合う．

## 決定事項
- 連続正解の数え方：1回目の答えで正解した問題だけ．1回目の誤り・答えないまま離れる（メニュー選択・再読み込み）で 0 に戻る．
- 圧縮率（ランレングス）は博士の指示で外した．答えは整数か小数第1位まで．
- 用語は「1フレームのビット数」．紙の版3の「1フレームのデータ量」とのそろえ方は，博士の確認待ち．
